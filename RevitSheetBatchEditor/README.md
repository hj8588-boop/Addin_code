# Revit 시트·도곽 일괄 수정

Revit 2024 프로젝트의 시트 번호, 시트 이름 및 도곽 인스턴스 문자열 매개변수를 표에서 일괄 수정하는 C# WPF 애드인입니다.

## 주요 기능

- 시트 번호와 시트 이름을 표에서 직접 편집
- 시트 번호 중복 사전 검사
- 번호 교환도 가능한 임시 번호 기반 2단계 변경
- 선택 시트의 시트 프로젝트/공유 매개변수 및 도곽 인스턴스 매개변수 공통 입력
- 시트 검색, 전체 선택 및 해제
- 실패 시 전체 작업 롤백
- Loader/Engine 분리로 Engine DLL 개발 교체 용이

## 빌드

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
.\build.ps1
```

기본 Revit 설치 경로는 `C:\Program Files\Autodesk\Revit 2024`입니다. 다른 경로라면 다음처럼 지정합니다.

```powershell
.\build.ps1 -RevitInstallDir "D:\Autodesk\Revit 2024"
```

## 설치

관리 권한 PowerShell에서 다음을 실행합니다.

```powershell
.\install.ps1
```

설치 후 Revit을 다시 시작하면 `도면 자동화 > 시트 관리 > 시트·도곽 일괄 수정` 버튼이 나타납니다.

## 개발 시 DLL 교체

- Loader DLL 또는 `.addin` 변경: Revit 재시작 필요
- Engine DLL 변경: 애드인 창을 닫은 뒤 DLL 교체 가능. 다음 버튼 실행 시 새 Engine을 로드

## 현재 범위와 주의사항

- 플레이스홀더 시트는 목록에서 제외합니다.
- 한 시트에 도곽이 여러 개면 첫 번째 도곽만 공통값 적용 대상으로 사용합니다.
- 시트에 바인딩된 프로젝트/공유 매개변수와 도곽 **인스턴스** 매개변수를 출처별로 표시합니다.
- 같은 이름의 매개변수가 여러 개라면 `LookupParameter` 특성상 첫 번째 항목을 사용합니다. 실무 공유 매개변수 GUID 기반 선택은 차기 확장 항목입니다.
